# CanvasIQ / Markov.ink

Whiteboard-native AI tutor. Static site, no build step.

- `index.html` – landing page
- `whiteboard.html` – the tutor app (paste your Anthropic API key in the gear menu)
- `pitch-deck.html` – investor deck (print to PDF with Cmd/Ctrl+P)

## Run locally
Open `index.html` in Chrome, or run `npx serve .` for mic/voice support.

## Deploy
Pushed to GitHub, hosted on Vercel. Every push to `main` redeploys automatically.
